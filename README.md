# Visual Vibe Creation

Official portfolio and website of Enosh Jaques.

This is an award-level creative digital studio portfolio designed to showcase cross-disciplinary software engineering, UI/UX designs, mobile applications, and motion graphic assets.

---

## Features

- **Next.js**: Leverages App Router structure, font optimizations, and dynamic sitemaps.
- **TypeScript**: Strictly typed systems for compile-time safety and maintainable codebase.
- **Tailwind CSS v4**: CSS-first configurations, clean variables mapping, and modern utility sets.
- **Framer Motion**: Premium interactive spring effects, layout-based filter animations, and text reveals.
- **Responsive Design**: Custom breakpoint support from 320px to 1920px (ultra-wide monitor support).
- **Premium Animations**: Integrated Lenis smooth scroll tracking.

---

## Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Transitions**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) (custom brand SVGs for social badges)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)

## Installation

Ensure you have [Node.js](https://nodejs.org/) installed (v18.x or above recommended).

1. Clone this repository locally:
   ```bash
   git clone https://github.com/Enosh-J10/visualvibecreation.git
   cd visualvibecreation
   ```

2. Install the project dependencies:
   ```bash
   npm install
   ```

---

## Development

To spin up the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your browser to preview the live application.

---

## Build

To compile a production-ready static export:

```bash
npm run build
```

The output will compile to optimized static page chunks inside the `.next` directory.

---

## Deployment

- **Hosting**: Connected to **Vercel** via GitHub triggers for continuous integration builds.
- **DNS & CDN Security**: Connected custom domain `visualvibecreation.com` through **Cloudflare** using CNAME mapping and Full SSL proxies.
